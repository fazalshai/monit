# Monit AED 💰 | UAE Expense Tracker & Spending Dashboard

A fast, private, and modern expense tracker designed specifically for daily spending in **AED (UAE Dirhams)**.

## ✨ Features
- **Quick Spending Entry**:
  - Enter amount in AED with instant quick-add increment pills (+10, +25, +50, +100, +500 AED).
  - Item description with auto-fill shortcut pills (Karak Chai, Carrefour Groceries, Salik, Fuel, etc.).
  - Category picker with colorful badges (Food 🍔, Groceries 🛒, Transport & Fuel 🚗, Shopping 🛍️, Bills 💡, Healthcare 💊, Leisure 🎬, Other 📦).
  - Payment method tracker (Apple Pay, Credit Card, Debit Card, Cash, Bank Transfer).
- **Executive Analytics Dashboard**:
  - **KPIs**: All-time total spend, current month spend vs budget, today's spend & transaction count, top category.
  - **Category Breakdown**: Interactive visual proportion bar and category cards showing exact AED amounts and percentages.
  - **Time Periods**: Filter insights by All Time, This Month, or This Week.
- **Spending History & Management**:
  - Real-time instant search by item name or notes.
  - Category filters and multi-criteria sorting (newest, oldest, highest amount, lowest amount).
  - Edit or delete transactions on the fly.
- **Budget & Data Security**:
  - Custom monthly budget target with live progress bar.
  - All data stays privately stored in your browser's `localStorage` (no sign-up or servers needed).
  - **Export to CSV** (compatible with Microsoft Excel and Apple Numbers).
  - **Export / Import JSON** backup anytime.
  - Dark & Light theme toggle.

## 🚀 How to Run

### Option 1: Direct in Browser
Simply double-click `index.html` or open it with Safari, Chrome, or any modern web browser.

### Option 2: Local Web Server
```bash
npm start
```
Then visit `http://localhost:3000` in your browser.
